# Roadmap

**English** | [简体中文](roadmap.zh-CN.md)

## Near term

- Expand format-compatibility fixtures for future Codex rollout schemas.
- Add a redacted diagnostics bundle command.
- Add optional path mappings for project working directories across devices.
- Improve scheduler acceptance tests on clean Windows and macOS hosts.

## Later

- Optional encrypted conversation payloads independent of transport encryption.
- A read-only fleet-health dashboard generated from device reports.
- Export/import adapters for additional local agent runtimes.

Roadmap items are not commitments. Safety and recoverability take priority over feature breadth.
